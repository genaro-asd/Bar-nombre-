# Bar El Refugio - Sitio Web Interactivo

## Descripción breve
Sitio web estático e interactivo para **Bar El Refugio**, diseñado para presentar la propuesta gastronómica del establecimiento, exhibir sus especialidades mediante un carrusel dinámico de imágenes y permitir a los clientes realizar reservas en línea con validación de datos en tiempo real mediante JavaScript.

## Instrucciones básicas de uso

1. **Clonar o descargar el repositorio:**
   ```bash
   git clone https://github.com/genaro-asd/Bar-nombre-.git
   ```
2. **Navegación local:**
   * Abre directamente el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Mozilla Firefox, Edge, etc.).
   * Alternativamente, si utilizas **Visual Studio Code**, puedes usar la extensión **Live Server** para ejecutar el proyecto en un servidor local.

3. **Funcionalidades principales:**
   * **Inicio (`index.html`):** Visualización del carrusel de especialidades. Permite cambiar de imagen con las flechas o dejar que avance automáticamente cada 3 segundos.
   * **Carta (`menu.html`):** Consulta la lista de productos y servicios con sus respectivos precios y categorías.
   * **Reservas (`contacto.html`):** Completa el formulario con tu Nombre, Email, Teléfono y Detalle de la reserva. Al enviar, el script validará los campos e imprimirá una tarjeta con el resumen de la confirmación.
